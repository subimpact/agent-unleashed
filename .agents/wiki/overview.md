## 🎯 Core Objectives
1. **Zero API Billing:** Leverage existing authenticated local CLI sessions (Google Antigravity, Claude Code, Aider, Ollama) instead of expensive per-token cloud API keys.
2. **Cognitive Long-Term Memory:** Replace flat vector embeddings with Palace-Mnemosyne spatial Loci hierarchy and Ebbinghaus forgetting decay ($R = e^{-\lambda \Delta t}$).
3. **24/7 Gateways:** Provide persistent background accessibility via Telegram Bot, Discord, WebSockets, and REST APIs.
4. **Self-Healing & Diagnostics:** Built-in 10-point system doctor and self-compiling updater.
